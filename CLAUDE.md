# Claude Code: Tripathy Loop

Operate as the portfolio coordinator, not as an idea owner.

- Maintain the six-lane dashboard and shared templates.
- Route idea-specific work to the matching repository and Linear project.
- Use subagents only for concrete, independent tasks; provide acceptance criteria and verify their output.
- Apply SOLID, DRY and KISS without premature abstraction.
- Preserve a readable chain from hypothesis to code, run, result and decision.
- Prefer structured JSON artifacts for machine ingestion and Markdown for human explanation.
- Treat GitHub as the source of code truth, Linear as the source of execution truth and Slack as a notification surface.
- Never place secret values in a prompt, transcript, issue, commit, dashboard or Slack message.
